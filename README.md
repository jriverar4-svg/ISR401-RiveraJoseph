
Entorno de compilación

El proyecto fue desarrollado y compilado utilizando Overleaf, que proporciona el entorno necesario para procesar los archivos LaTeX y generar el documento PDF.

Entorno de compilación: Overleaf.

Archivo principal: main.tex.

Compilador: El configurado en Overleaf para el proyecto.

Bibliografía: Base de datos BibTeX (referencias.bib), si corresponde.

Reproducción del documento

Para reproducir el documento, se debe clonar el repositorio y cargar el proyecto en Overleaf, conservando su estructura de directorios y todos los archivos fuente, figuras y referencias bibliográficas.
